# 결 · 나의 자소서 작업실

기존 글에서 경험과 말투를 분리해 보관하고, 새 자소서 작성과 퇴고에 사용합니다. 확인한 수정 원칙을 다음 글에 적용합니다. 현재 버전은 Mac에서 쓰는 개인용 앱입니다.

## 시작

`작업실 열기.command`를 더블 클릭합니다. 브라우저에서 `http://127.0.0.1:4317`에 접속합니다. 실행 창은 사용 중 열어 두세요. 터미널에서는 이 폴더에서 `npm start`로 실행합니다.

Node.js 22 이상과 로그인된 Claude Code가 필요합니다. 이 Mac에서 Claude 연결을 실제로 확인했습니다. AI 버튼을 누르면 해당 Claude 계정의 사용량을 사용합니다. 별도 API 키는 필요하지 않습니다.

## 사용 순서

1. 원문·참조 자료에서 글을 붙여 넣고 원문만 보관합니다. 이 단계에서는 새 자소서 작성에 사용되지 않습니다.
2. 확인한 경험과 근거를 정리합니다. 말투를 참고할 경우 문체 원칙과 오류를 제거한 예문을 별도로 넣습니다. 사실 확인란을 체크하고 참조용으로 저장합니다.
3. 작성·퇴고에서 승인된 참조 자료를 선택합니다. 초안은 확인 후 적용하고 저장합니다. 초안을 저장해도 자동으로 참조용이 되지 않습니다.
4. 잘못된 주장을 발견하면 정정 기록에 틀린 표현, 올바른 내용, 근거를 적습니다. 해당 표현이 있는 참조 자료는 사용 중지되고 원문은 보존됩니다. 정리본을 수정하고 다시 확인해 참조용으로 저장합니다.
5. 보관함에서 저장한 자소서와 이전 버전을 확인하거나 전체 자료를 백업합니다.

## 저장과 전송

자료는 `data/workspace.json`에 저장하고 직전 저장본을 `.bak`로 보관합니다. 데이터 폴더는 Git에 포함하지 않습니다. 앱은 `127.0.0.1`에서만 접속을 받습니다.

AI 작업을 실행할 때 선택한 참고 경험, 원문과 분리한 승인된 말투 예문, 활성화된 선호 원칙, 문항 및 현재 입력을 Claude 서비스에 보냅니다. 선택하지 않은 경험과 수정 전후 이력은 새 요청에 넣지 않습니다. AI 프로세스의 파일·셸·외부 도구를 끄고 대화 세션 저장도 끕니다. 서비스 자체의 데이터 처리 정책까지 바꾸지는 않습니다.

자료의 말투를 참고하고 승인한 선호를 다시 입력하는 방식입니다. 모델 가중치를 훈련하지 않습니다. 원문 인용 일치 검사는 사실의 진위나 문항 적합성을 보증하지 않습니다. 제출 전에는 사실, 수치, 문항 적합성을 직접 확인해야 합니다. 글자 수 초과는 표시하며 문장을 임의로 잘라내지 않습니다.

분석·작성 중 입력이 달라지면 결과를 자동 적용하지 않습니다. 여러 창의 동시 저장은 개정 번호로 충돌을 감지합니다. 저장 파일이 손상되면 빈 자료로 덮어쓰지 않고 실행을 중단합니다.

## 개발과 검증

외부 라이브러리 설치 없이 Node 기본 모듈과 브라우저 기능으로 실행합니다. `npm test`는 자료 선택, 선호 범위, 인용 검사, 백업 검증, 저장 충돌과 다른 사이트의 요청 차단을 검사합니다.

`SELFVOICE_DATA_DIR`은 저장 경로, `PORT`는 로컬 포트, `SELFVOICE_CLAUDE`는 Claude 실행 파일, `SELFVOICE_MODEL`은 모델을 지정합니다. 기본 모델은 `opus`, 사고 수준은 `high`입니다.

공개 서비스로 배포하려면 사용자별 인증 및 자료 분리, 서버용 AI 인증과 비용 제한이 필요합니다. 현재 개인용 서버를 인터넷에 노출하는 방식으로 배포하지 않습니다. UI, 도메인 규칙, AI 실행과 저장 경계를 분리해 후속 확장이 가능하도록 했습니다.

## 원문과 참조 자료 분리

원문 분석 버튼은 사용자가 지정한 원문을 AI에 보내 분석 제안을 받습니다. 분석 제안은 자동 승인되지 않습니다. 일반 작성·퇴고 요청에는 보관 원문이 전달되지 않고 승인한 정리본만 전달됩니다. 기존 자료와 백업 중 승인 상태가 없는 자료도 보관 전용으로 읽습니다.

정정 표현 검사는 문자열 기반이며 공백과 대소문자 차이를 무시합니다. 의미가 같은 다른 표현까지 완벽하게 검출하는 기능은 아닙니다. 근거와 확인일은 확인 기록이며 외부 사실의 진위를 자동 보증하지 않습니다.

## 대화에서 선호 기록하기

말투 기록 화면에서 Codex 또는 Claude Code를 선택하고, 직접 쓴 수정·지적과 AI 비교 문장을 분리해 입력합니다. 제안받은 원칙과 사용자 인용 근거를 확인하고 적용 범위를 선택한 뒤 저장합니다. 기본 범위는 이번 글입니다. AI 문장과 채팅의 반말·축약은 말투 예문으로 취급하지 않습니다. 이후 작성에는 저장한 원칙만 보내며 대화 원문은 보내지 않습니다.

예문의 문장 길이는 변화와 분포를 관찰하는 데만 사용합니다. 모든 문장을 짧게 만들거나 예문의 비유·다짐을 모든 문항에 적용하지 않습니다.

## 검증 범위와 한계

자동 테스트는 자료 선택·적용 범위·저장과 AI 요청 경계를 검사합니다. HTTP 통합 테스트는 가짜 AI 실행 파일로 실제 전송 내용을 확인하므로 모델의 문체 품질 점수가 아닙니다. 개인 문체 재현은 본인 작성 여부가 확인된 글을 따로 확보하고, 평가할 원문을 생성 입력에서 제외해 비교해야 합니다. 예문을 넣었다는 사실이나 인용문 일치만으로 개인 말투를 재현했다고 판정하지 않습니다. 말투 예문과 승인된 선호가 없는 작업실은 개인 문체가 설정된 상태가 아닙니다.
